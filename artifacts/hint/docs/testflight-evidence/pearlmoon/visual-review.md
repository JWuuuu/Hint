# 畫面檢視紀錄

此頁描述實際檢視截圖的結果；完整的尺寸／互動斷言見 coverage。測試人物與出生資料全部為虛構。

- **Astrology 一般尺寸**：檢視珍珠淺色主頁、深梅紫星座故事、互動輪盤、配置詳情與行運時間。層級、字體、細線與內容間距一致；原先星盤詳情滑入畫面外的過場已改為局部淡入／微幅縮放。
- **Pro Max 200% 文字**：檢視英文星盤頂部、中／西文深色詳情、日文配置清單、韓文星座故事。長名稱與標題自動換行，關閉按鈕保留完整觸控區。
- **SE 200% 文字**：逐一檢視英文底部與預覽入口、中／日文詳情、西文配置清單、韓文星座底部。詳情標題保留在可視區，長內容由內部區域捲動；最後內容在底部導航上方可達。
- **從零建立星盤**：兩種手機均走完探索 → 出生地搜尋 → 出生日期對應時區 → 資料確認 → 本機保存 → 實際配置詳情 → 重新整理恢復。不需要 email；沒有把出生資料直接預先塞進完成狀態。
- **Profile**：西文放大文字的儲存按鈕可包住完整文字，出生時間與地點依手機寬度堆疊。
- **History**：補拍動畫結束後的英文／西文兩種手機畫面，另檢視 SE 西文長網址詳情。原始長網址完整換行，卡片沒有撐破畫面。過場中的淡入截圖沒有被誤判為最終文字對比。

星盤／詳情中段與底部截圖可能只顯示段落的後半，或頂端保留上一列的部分內容；這是實際捲動邊界。完整文字仍在可捲動內容中，並以頂／中／底截圖及互動檢查交叉核對。History 的橫向篩選列也保留可捲動行為。

這些結果不是原生鍵盤、Dynamic Type、實機觸覺或 iPhone GPU 效能驗收。
