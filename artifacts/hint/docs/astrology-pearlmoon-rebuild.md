# Hint Astrology「珍珠月光」重建與補漏驗收

本輪保留本機 beta、裝置身份與私人合盤界線。沒有部署、上傳 TestFlight、呼叫付費占星／AI、寄出邀請或修改真實帳號資料。

## 新體驗

主要入口是「探索星座／我的星盤／此刻行運」。首次直接進入 Astrology 或合盤時，不需要先完成 email onboarding；其他房間的首次使用流程維持原有行為。

- 十二星座都有獨立、可返回與重新整理的 URL 狀態。文章包含核心主題、元素／模式、生活例子、反思問題及對應的個人配置入口。
- 出生資料先填寫，再確認，最後保存到目前裝置檔案。未知時間可以保存，不會猜測月亮、上升或宮位。
- 星盤包含個人摘要、三大配置、互動輪盤、配置／相位／宮位清單與可捲動詳情。行星的計算位置固定，擁擠時只移動外側標籤；清單提供完整替代操作。
- 星盤、行星、宮位與相位選取可以直接連結。放大、焦點、Escape、返回焦點及底部捲動均有回歸範圍。
- 行運只提供現有服務支援的今日／本週，依實際返回日期顯示當下天體 → 出生配置。精確時間保留時刻與已提供的時區；不猜測模糊日期或未提供的時區。
- 合盤保留同意、邀請與雙方私人存取。直接計算顯示真實相位；舊邀請結果若只有出生配置，就明列詳細連結尚未提供。移除本地公式的百分比與衍生關係判語，既有保存資料不受破壞。
- 深入報告維持明確預覽。

視覺採珍珠白、霧玫瑰、香檳金與柔紫；深色是深梅紫。使用原創 SVG 星座符號、襯線標題、薄線與分層留白。動效以 120ms 按壓、220ms 頁面過場、600ms 星環為主；操作不等待儀式動畫。App 或系統任一減少動態開啟即停止裝飾動效；微光離開畫面或 App 進入背景時停止。

## 確認問題與修正證據

| 編號 | 原問題／重現 | 修正與回歸範圍 |
|---|---|---|
| A1 | 同一個本機檔案在兩個分頁首次連線取得不同伺服器身份 | 共用 Web Lock；鎖內重新讀取憑證，持久保存後才使用。兩個獨立 manager、初次身份建立、儲存失敗與切换佇列測試。 |
| A2 | 另一分頁切換檔案時，舊分頁把新姓名寫入舊身份快照 | 身份世代、BroadcastChannel、持久切換日誌與失敗恢復；帳號改用 owner 索引，舊資料保留。涵蓋中途寫入、A→B→A、晚回應及重新啟動。 |
| A3 | Daily 初始載入 A 晚於筆記 B 保存成功，畫面回到 A | 筆記載入版本與保存版本分離，允許牌卡更新但不覆蓋新筆記。 |
| A4 | Tarot 小票 Tab 進入背景、Escape 無法關閉 | 沿用共用 Dialog；小票與放大卡片補焦點隔離、Escape、背景鎖定與返回焦點，保留原有抽牌／閱讀流程。 |
| A5 | SE 西文 200% 文字超出 Profile 固定 48px 按鈕 | 按鈕最小高度、自適應內距；出生時間與地點在手機單欄排列。 |
| A6 | History 長網址把 375px 畫面撐至逾 1500px | 內容任意斷行、容器允許收縮；Open 操作最少 44px。 |
| A7 | Profile 錯誤英文、History 計數英文、Open 誤用未提供翻譯 | 分開情境翻譯，補完整五語錯誤、操作、統計與輔助名稱。 |
| A8 | 新 warm invitation 被較晚的 cold launch URL 蓋掉 | 有較新的有效連結後不採用舊啟動結果；失效連結不阻止有效 cold link。 |
| A9 | Synastry 失敗 fallback 被快取 30 天，重試不重新計算 | 僅快取真實成功結果，忽略既有負面快取；模擬 provider 失敗後恢復。 |
| B1 | Journal 在清除歷史後完成 INSERT，復活舊紀錄 | 隔離 PostgreSQL trigger 重現；保存／清除共用 owner transaction lock 與時間界線；前端阻止晚回應恢復 cache，仍只清除相符的已保存草稿。 |
| B2 | 原生背景事件到達後，Tarot 裝飾 Framer 動效仍 repeat=Infinity | CardWashRitual 使用共用 quietMotion；以真實 MotionPolicyProvider 的模擬 native 事件驗證停止、恢復與卸載。這是程式整合證據，不是實機測量。 |
| B3 | Tarot 手動洗牌在原生背景事件後仍持續 RAF 與卡片繪製 | 隔離測試確認背景 8 幀仍增加 8 次繪製；手動動效改依共用可見狀態停止，恢復沿用既有 Prepare 流程，重新開始只建立一個循環，卸載清理。 |
| R1 | 新星盤重新計算時切頁，返回後卡在 loading | 取消未完成工作並釋放請求狀態；已完成結果不因切頁重算。 |
| R2 | 清除後的晚星盤／合盤回應或舊 cache 遷移恢復結果 | 請求、記憶體、React Query 與持久 cache 都以 owner／出生指紋／clear version 隔離；清除後不自動付費重算，主動新計算仍可用。 |
| R3 | 星盤詳情關閉後焦點留在 body | 回到原控制項；直接連結或原控制項消失時有可用的頁面控制替代。 |
| R4 | 將未知宮制或 whole-sign 第一宮宮頭當成精確上升度數 | 只使用 provider 明確返回的 Ascendant；沒有返回時保持未知。 |
| R5 | My Chart 已保存，離線去 Compatibility 仍向另一端點重算 | 共用已驗證星盤 adapter、出生指紋、計算設定與 owner cache，保留舊 API 相容介面。 |
| R6 | 行運 Ascendant 名稱無法選取 rising，或時間只有日期 | 正規化合法天體別名，只連結已返回配置；保留實際開始／精確／結束時刻。 |
| R7 | 合盤已有完整出生資料，但星盤計算失敗後顯示空表單且沒有重試 | 保留出生資料，分開載入／失敗，提供防連點重試；五語錯誤不顯示 provider 技術內容。 |
| R8 | 星盤詳情的預設滑入動畫短暫移出手機畫面 | 改為 220ms 淡入與微幅縮放，關閉淡出 180ms；兩種手機、四種動態設定與放大文字均檢查彈窗邊界。 |
| R9 | Tarot 恢復資料在切換身份中途寫入另一檔案，或已清除歷史被另一分頁的 sessionStorage 恢復 | 恢復記錄改以 owner 索引並攜帶歷史世代；預先存在的回呼不能保存已刪除版本，明確開始新閱讀後才可建立新恢復記錄。 |
| R10 | WebKit 對成功的 204 空回應提供空 stream，回應封裝拋錯，使清除歷史一直要求重試 | 空 body 狀態與 HEAD 明確使用 null body；保留身份檢查與追蹤標頭。WebKit 隔離重現及 204／205／304 回歸由失敗轉通過。 |

## 內容與資料

五語新增內容包括：12 篇星座文章、每個星座的太陽／月亮／上升解讀、11 個天體／上升說明、12 宮與 5 大相位。一般知識與依據實際配置的解說明確標示；使用者姓名與原始生成文字不擅自翻譯。未返回的資料不補畫，不把教學模板稱為完整深入報告。

新增相容 metadata：`calculation.zodiacSystem`、`requestedHouseSystem`、確認或未知的 `houseSystem`、實際返回數量。OpenAPI／產生型別同步。Journal `editedAt` 與歷史界線回應也保持舊請求相容。本輪沒有新增 SQL schema 變更；既有增量 migration 的隔離重複／並行／回滾／備份還原測試納入最終驗收，不使用 `db:push`。

## 同版本驗收

最終結果：560 個前端測試、54 個 API／資料庫測試、492 個手機 E2E 通過；另有 20 個按原定範圍跳過。檔案雜湊、逐案例覆蓋、截圖與效能紀錄見 [完整驗收報告](testflight-evidence/pearlmoon/README.md)。

| 範圍 | 驗證內容 |
|---|---|
| 功能 | 全部單元／元件測試、API 與隔離 PostgreSQL、型別、前後端建置；原有 Tarot 九牌陣、閱讀、追問、保存恢復及分享流程。 |
| 畫面 | SE 375×667、Pro Max 440×956；五語 × 明暗 × 四種動態設定；長名稱、長網址、200% 網頁文字、實際 top／middle／bottom 捲動與截圖。 |
| 無障礙 | 44px 控制範圍、文字完整邊界、固定層遮擋、Dialog 焦點與 Escape、輪盤以清單替代操作。 |
| 動效 | WebKit host RAF 與重複互動、App／系統減少動態、離開畫面及模擬原生背景事件；不能當成實體 iPhone frame-time 證據。 |
| 資料 | 全部虛構身份、假 provider 與獨立 PostgreSQL；不以更新快照掩蓋失敗。 |

## 尚未驗證的發布必要項目

正式 API／公開邀請／下載 HTTPS 網址、Apple Team ID、Xcode／SDK／簽章尚未提供或完成。實體 iPhone 的冷啟動、鍵盤／組字、語音權限、原生分享取消、觸覺、背景生命週期與 60Hz 效能仍未驗證。素材／隱私與正式發布設定仍需既定 release checklist 驗收。

因此本輪是程式與隔離測試的候選版本，不宣告原生發布就緒，也不部署或上傳 TestFlight。
