# Hint repair register

This register describes the implemented behavior and repeatable checks. Final pass counts, source hashes and release blockers belong to [the candidate report](./testflight-candidate.md). The original plan groups the 13 issues into batches; individual historical numbers are not inferred here.

## Deliberate preview functions

Formal account authentication/cross-device recovery, complete Dream interpretation and deep astrology reports are labelled previews. This work does not expand them into live products. Browser fixture replies do not establish live model or astrology-provider accuracy.

The release decision must follow actual final evidence. Device, hosting, signing, privacy/provider retention, asset rights and operating configuration gaps cannot be turned into passed checks by a successful web build.
