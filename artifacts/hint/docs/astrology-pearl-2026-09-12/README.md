# Hint — Tarot 精修與珍珠月光 Astrology

本輪完成的程式集中在 Tarot 與 Astrology。現有本機 beta 身份、私人邀請存取與已通過的抽牌邏輯保留；未部署、未上傳 TestFlight、未操作真實紀錄，也未呼叫付費占星／AI 服務。

新版 iPhone 框預覽：<http://127.0.0.1:5240/app/tarot?hintPreview=frame>、<http://127.0.0.1:5240/app/astrology?hintPreview=frame>。這是隔離的 production web 預覽；真實 API 未接入此預覽。下面的星盤、比較盤、報告截圖與樣本使用明確的虛構 QA 資料，不能當成個人的真實計算結果。

整合狀態：**使用者暫停並轉移至 Windows**。最後一輪 E2E 已記錄 255 通過、12 預定跳過、0 失敗；342 項中有 75 項尚未記錄完成。詳見專案根目錄 `HANDOFF_WINDOWS.md` 與本目錄 `checkpoint-status.json`。本機預覽目前已停止，桌機需重新啟動。

## 資料與內容規則

跨人物相位政策 `hint-angular-v1`：合相／對分 8°、三分／四分 6°、六分 4°。以最短圓周角距計算，保留原始黃經精度；顯示文字最多四位小數，不改寫圖上的實際位置。[供應商文件](https://astrologyapi.com/developers/v1/western/synastry_horoscope)包含個別盤及 composite 資料，因此本輪的跨人物相位採獨立幾何推導。

報告 schema 為 1，內容版號 `pearl-letter-1`；新合盤結果 schema 為 2。報告保存雙方輸入／計算快照與五語全文。切換語言只換文字，修改出生資料使目前計算失效，歷史原版本保留。Fallback 不會變成已完成的個人报告；計算資料缺少宮位、相位或配置時明示部分報告，不補猜。

相位摘要只在呈現層挑選，完整清單與保存快照不截斷。比較盤與組合盤分開；本輪沒有增加組合盤、PDF、任意日期預測或付費長報告。

## 資料庫、API 與復原演練

本輪沿用既有 PostgreSQL JSONB 保存新版合盤快照，沒有增加 SQL migration。既有六筆增量 migration 在臨時資料庫驗證：重複執行、並行鎖定、失敗回滾、ledger 雜湊檢查及舊資料保留。

停機備份再以相同 PostgreSQL build 還原到另一個臨時埠：11 張表的內容摘要全部相同，6 筆 migration 紀錄完整。這是本機冷備份演練，不代表託管環境的 PITR 已驗證。

Production API 隔離 smoke 確認 liveness／readiness、裝置 session、偽造 owner 隔離、公開邀請不暴露出生資料、服務失敗不完成合盤、交易清除保留 Profile、撤銷憑證失效。臨時 API 與資料庫已停止，未變動真實資料庫。

復原方式：保留目前候選來源與資產雜湊；若回退前端，使用同批已驗證 assets，保留 IndexedDB 舊版報告；若回退新比較結果呈現，維持舊 JSONB 快照可讀，不能重跑 schema push 或刪除舊報告來達成回退。
