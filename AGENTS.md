# Repository contribution conventions

- Use the human contributor's configured Git name and email for new commits. Do not attribute authorship, committer identity, or co-authorship to an AI assistant.
- Preserve existing human author identities when moving or applying commits.
- Use descriptive branch and tag names without AI tool names or prefixes.
- The active repository is https://github.com/JWuuuu/Hint. Keep setup and handoff links pointed at this repository.
